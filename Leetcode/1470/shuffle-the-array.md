# Shuffle the Array


Given a list of 2n elements shuffle them so that it becomes an array of exchanging elements.
\[x1,y1,x2,y2....,xn,yn\]

I am approaching this as intuitively as possible. 
Define a new array and iterate 1 to n ( whole length is 2n) while adding i and i+n to the new array. 
O(n)
